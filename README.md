# ClipShelf
clipファイルの管理

CLIP STUDIO PAINT の一枚絵（`.clip`）を、サムネイルで探せるWindows用ローカルアプリの試作です。

## できること

- フォルダとサブフォルダから `.clip` を一覧に表示
- 保存済みプレビュー画像によるサムネイル表示
- タグ・メモ・お気に入り、キーワード検索、更新日・名前による並べ替え
- フォルダ移動・ファイル名変更後の再スキャンと再接続
- 一覧からCLIP STUDIO PAINTで作品を開く、保存場所を開く
- 管理情報のSQLiteバックアップ

作品ファイルは読み取り専用で扱います。タグなどはアプリフォルダ内の `data/` に保存し、ネットワーク通信は行いません。

## 起動

1. このリポジトリをダウンロードまたはcloneします。
2. Windowsで **Start.cmd** をダブルクリックします。
3. **＋ フォルダを登録** から作品の保存先を選びます。

Windowsと **Python 3.10以降（tkinterを含む）** が必要です。必須の追加Pythonパッケージはありません。Pillowがインストールされている場合は、プレビューを滑らかに縮小します。

コマンドから起動する場合：

```powershell
python clip_shelf.py
```

作品を開くには、Windowsの `.clip` の既定アプリをCLIP STUDIO PAINTに設定してください。

詳細は [使い方.md](使い方.md) を参照してください。

## フォルダを移動したら

移動先が未登録の場合は、そのフォルダを追加して再スキャンします。元の保存先が見つからず、内容が完全一致する候補が一つであれば、タグ・メモ・お気に入りを引き継ぎます。

コピーが複数ある場合や、移動と同時に再保存した場合は「移動先の .clip を指定」で手動接続できます。未接続のドライブは登録を保持します。

## 検証

Python標準ライブラリの `unittest` で16項目を検証しています。

```powershell
python -m unittest discover -s tests -v
```

移動・改名、コピーの区別、編集後の再接続、タグ・メモ保持、ドライブ未接続、読み取り失敗、キャンセル、バックアップ、元作品を変更しないことを確認します。

公開されている [clipstudio.js](https://github.com/saitolume/clipstudio.js) の実際の `.clip` サンプルでも、プレビュー抽出とデコードを確認しています。サンプルファイルやユーザーの作品・管理情報は、このリポジトリには含めていません。

## 試作版の範囲

- 表示する画像はファイルに保存されたプレビューです。レイヤーや原寸のキャンバスを描画する機能はありません。
- 一部の形式やバージョンではプレビューを取得できない場合があります。
- 複数ページ漫画の `.cmc` 管理、CLIP STUDIO公式の作品一覧修復、クラウド同期は対象外です。
- すべてのCLIP STUDIO PAINTバージョンや保存環境との互換性は未確認です。

セルシスの公式製品ではありません。
